================================================================================
  DRY BEAN PROJECT — LOCAL RUN (STEP BY STEP)
================================================================================
  Windows PowerShell | Project folder: Karunadu Project
================================================================================

BEFORE YOU START
----------------
1. Install Python 3.9 or newer (NOT 3.7):
   https://www.python.org/downloads/
   Check:  py -3.9 --version

2. Open PowerShell and go to the project:
   cd "C:\Users\surij\Downloads\Karunadu Project"


ONE-TIME SETUP (first time only)
--------------------------------
py -3.9 -m venv .venv
.\.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt


EVERY NEW TERMINAL SESSION
--------------------------
cd "C:\Users\surij\Downloads\Karunadu Project"
.\.venv\Scripts\activate


RUN THE PIPELINE (in this order)
-------------------------------

STEP 1 — Prepare data (~1 min)
  python Scripts\data_alignment.py

  Expect: "Rows=13611  Columns=23"


STEP 2 — Train & benchmark models (15–40 min with tuning)
  python -u Scripts\benchmark_models.py

  Expect: PHASE 1, PHASE 2, PHASE 3 and [SUCCESS] Model saved
  Best model is usually: svm_tuned (~93.6% accuracy)

  TOO SLOW? Edit config\benchmark_config.yaml:
    enable_tuning: false     (fast test, ~3 min)
    tuning_top_n: 1          (only tune SVM)


STEP 3 — Charts (~2–5 min)
  python Scripts\visualize_results.py

  Outputs:
    reports\performance_chart.png
    reports\learning_curves.png


STEP 4 — SHAP explainability (optional, ~1–3 min)
  python Scripts\explain_model.py

  Output: reports\shap_importance.png


STEP 5 — Prediction API (optional)
  python app.py

  In another PowerShell window:
    curl http://localhost:5000/health
    curl http://localhost:5000/info

  Stop API: Ctrl+C in the app.py window


STEP 6 — Interactive single prediction (optional)
  python Scripts\predict.py
  (Enter each feature value when prompted)


VERIFY FILES EXIST
------------------
  Data_sets\train_dataset.csv
  models\best_model.joblib
  models\model_metadata.json
  reports\benchmark_results.csv
  reports\confusion_matrix.json
  reports\performance_chart.png
  reports\learning_curves.png


OPEN RESULTS
------------
  start reports\performance_chart.png
  notepad reports\benchmark_results.csv
